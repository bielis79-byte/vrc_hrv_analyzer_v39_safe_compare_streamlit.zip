# VRC / HRV RRi Analyzer Pro v3.9 SAFE

Versión estable para Streamlit.

Incluye:
- Subida de uno o varios registros RRi.
- Segmentación Basal + E1-E6 + R1-R3.
- Ventanas de duración libre.
- Comparación entre registros por fase y variable.
- RRi superpuesto por fase.
- Exportación Excel y ZIP.
- HVG opcional para evitar bloqueos por exceso de cálculo.

Ejecutar:

```bash
streamlit run app.py
```
